## WorldJen

If a task mentions WorldJen, follow the matching skill:

- Install / verify the SDK / CLI → `worldjen-install`
- Runner host setup or operations (Linux + systemd) → `worldjen-runner`
- Create or inspect evaluation runs → `worldjen-runs`
- Public leaderboard → `worldjen-leaderboard`
- Playground or Rank sandbox → `worldjen-sandbox`

`worldjen-runs` covers evaluation jobs (the actual work). `worldjen-runner` covers the GPU worker host that executes them. They are different.
